## 已发现、尚待逐项验证的实现差异

- Normal基准写 Z90=1.64，而标准正态90%分位数约为1.28155；其方差组合也与论文公式（7）不同。
- 原代码BM1/BM2由 sf_rnn 的均值构造，需对照论文分位数预测与逐期优化定义。
- README称预测字段为补货量，但库存函数又减去历史库存；需确认作者实际将字段作为目标库存还是订货量使用。
- get_agginv 在到货时对负库存的处理没有直接沿用公式（1）的积压需求更新；同时需要检查是否产生负补货、提前期使用预测值还是实现值、计费是否覆盖完整区间。现有OPT列不能不经核对就作为重建仿真器的严格下界。
- 实地实验回归没有显式加入截距，而论文公式（11）包含截距；旧写法 DataFrame.drop('y',1) 在较新pandas下需要兼容修改。
- 实地实验成本循环使用前T-1个库存点，缺货率分母为T；需确认库存序列含期初或期末点的定义。前后期观察窗口也需核对。
- 匹配Notebook计算了倾向得分，但近邻实际在协变量上进行，需区分复现代码行为与严格的倾向得分匹配。
